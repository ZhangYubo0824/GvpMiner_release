# Final experimental results

This directory contains final catalogues and occurrences, candidate-level statistical outputs, selected stability evidence, sequence representations, numerical source tables and fourteen final figures with captions. Unsupported, no-output and unevaluable candidate states are retained.

Start with `catalogues/GvpMiner_candidate_evidence_latest.csv` and the six-method `paper/source_data/Table_S14_candidate_status.csv`. Read [the results guide](../docs/RESULTS_GUIDE.md) for annotation eligibility fields and denominators.

New outputs, intermediate features, models, embeddings, alignment caches and logs belong under `../work/`. `paper/` contains scientific figure inputs and numerical source tables.
